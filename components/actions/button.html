按钮 Button

触发操作的控件：表单提交、确认、导航之外的一切「做事」入口。四个变体 + 三档尺寸 + 加载 / 禁用状态，全部走主题 token，随上方主题与明暗切换即时变色。

meta-design · components/actions/button.html

什么时候用

  • 页面里最重要的那一个动作用 primary，其余用 secondary / ghost 拉开层级。
  • 耗时操作（保存、提交）给 isLoading：转圈时保持可聚焦（aria-busy，不是 native disabled），键盘焦点不会丢。
  • clickAction 传 async 函数，promise pending 期间自动显示加载态。

不要

  • 同一屏放两个 primary —— 主次会被稀释。
  • 用按钮做跳转 —— 只是换个页面的话用 Link。
  • 破坏性操作不加确认直接挂 destructive。

关键 props

  • label 必填，同时充当无障碍名
  • variant primary / secondary / ghost / destructive
  • size sm / md / lg
  • isLoading · isDisabled · tooltip
