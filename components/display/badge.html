徽标 Badge

一眼可见的状态与分类标识：Badge 打语义状态与分类标签，StatusDot 打在线 / 严重度（必须配文字），Indicator 是选择控件的装饰性指示器，Avatar / AvatarGroup 打人。全部走主题 token，随上方主题与明暗切换即时变色。

meta-design · components/display/badge.html

什么时候用

  • 每个状态徽标都在抢注意力 —— 只给需要用户注意或处理的状态上 success / warning / error。
  • 颜色变体（blue、purple、teal…）做分类标签：团队名、内容类型、优先级，一两个词就够。
  • StatusDot 必须配可见文字；label 播报给读屏，颜色永远不单独承载含义。

不要

  • 给每行都挂绿色「运行中」—— 满屏同款徽标等于没有信息，只剩噪音。
  • 用徽标承载元数据（时长、计数、日期）—— 那是 Text type="supporting" 的活。
  • 让徽标可点击 —— 它是只读指示器，要操作用 Button / Link。

关键 props

  • Badge：label 必填 · variant 语义 neutral / info / success / warning / error + 9 个颜色变体
  • StatusDot：variant + label 必填 · isPulsing · tooltip
  • CheckboxIndicator / RadioIndicator：state 必填，装饰性（aria-hidden），input 与键盘归 CheckboxInput / RadioList
  • Avatar：name（首字母 + alt）· size · shape · status 槽放 AvatarStatusDot · AvatarGroupOverflow 的 count 必填
