卡片 Card

装「一件独立的东西」的容器：能单独重排、删除、交互的条目才配一张卡。三个形态各司其职 —— Card 静态容器、ClickableCard 整卡跳转或动作、SelectableCard 多选开关；变体与阴影全部走主题 token，随上方主题与明暗切换即时变色。

meta-design · components/display/card.html

什么时候用

  • 先问「这件东西能单独重排或删除吗？」—— 能，才是卡片；不能，它只是页面区块，标题加间距就够了。
  • 卡片装离散条目：一份用户资料、一条通知、一个指标、网格里的一个商品；兄弟卡片的 padding 保持一致，网格里才对得齐。
  • 整卡可点用 ClickableCard（href 跳转或 onClick 动作），多选勾选用 SelectableCard；需要「头 + 可滚内容 + 底部操作」再上 Layout。

不要

  • 默认拿卡片做视觉分组 —— 标题加间距就能建立层级，不必到处加边框。
  • 把页面区块（「通用设置」、表单组）包进卡片，或在卡片里再套卡片。
  • 用彩色变体表达状态 —— 状态交给 Banner / Badge，彩色卡片只用于分类。

关键 props

  • Card：variant default / transparent / muted + 12 个彩色分类变体 · elevation none / low / med / high · padding 间距步进
  • ClickableCard：label 必填（无障碍名）· href 或 onClick · isDisabled（保留 Tab 停点）
  • SelectableCard：label · isSelected · onChange 三项必填，受控切换，多选用 Set 存 id
