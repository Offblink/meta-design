列表 List

一组有意义的条目：List 负责标题、分隔与密度，ListItem / Item 负责「前导槽 + 标签 + 描述 + 尾槽」的行结构，MetadataList 负责键值对详情。三个示例 —— 可点的活动列表、静态的有序步骤、以及 Item 行原语与元数据面板。

meta-design · components/display/list.html

什么时候用

  • 给列表一个 header 标题：既给上下文，也让读屏通过 aria-labelledby 引用整组。
  • 头像、徽标、时间戳放 startContent / endContent 槽位，别拼进 label 文本里。
  • 键值对详情（环境、版本、状态）用 MetadataList：值短 label.position="start"，值长用 top，长列表用 maxNumOfItems 折叠。

不要

  • 在一个列表里混可点行和不可点行又不给视觉区分 —— 用户分不清哪里能点。
  • 在可交互行里再放按钮 / 链接 —— 嵌套点击目标让焦点行为混乱。
  • 用 List 展示单条内容或互不相关的内容 —— 列表意味着一组有意义的集合。

关键 props

  • List：header · density compact / balanced / spacious · hasDividers · edge padded / flush / outset / bleed · listStyle none / disc / decimal
  • ListItem / Item：label 必填 · description · startContent / endContent · onClick 或 href
  • MetadataList：columns single / multi · label.position start / top · maxNumOfItems · title
