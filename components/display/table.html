表格 Table

结构一致的行列数据用表格呈现：5 条服务的示例数据跑两个表 —— 基础版展示 data + columns 数据驱动与富单元格（renderCell 组合 StatusDot），紧凑版叠加 density / dividers / isStriped / textOverflow，并用 proportional、pixel 声明列宽。列放不下时 Table 自己出横向滚动区。

meta-design · components/display/table.html

什么时候用

  • 列结构一致的数据集才用 Table；用 density 与 dividers 匹配信息密度和扫读需求。
  • 富单元格用 renderCell 组合 Astryx 组件：状态列放 StatusDot / Badge，人名列放 Avatar。
  • 列宽用 proportional(n) / pixel(n) 声明；列太多放不下时 Table 的滚动区自动接管横向滚动。

不要

  • 列结构不一致的数据别用表格 —— 换 List 或 Card 布局。
  • 一次开满所有插件（排序、选择、分页、列管理全上）—— 只加用得到的。
  • 长文本列只靠默认 60px 下限硬扛 —— 给它 proportional(1, {minWidth}) 自己的下限。

关键 props

  • data + columns：列定义 {key, header, width?, align?, renderCell?}，renderCell 收整行 item
  • idKey 行键 · density compact / balanced / spacious · dividers rows / columns / grid / none
  • isStriped · hasHover · textOverflow wrap / truncate
