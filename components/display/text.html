文本 Text

排版层级一页看全：Heading 输出正确的 h1–h6 标题层级，Text 用语义 type 渲染正文 / 标签 / 辅助 / 代码，Blockquote 带出处引用，Link 做导航链接，Kbd 展示快捷键。字号字重颜色全由主题 token 决定，换主题即时生效。

meta-design · components/display/text.html

什么时候用

  • 正文、标签、辅助文字一律用 Text 的语义 type（body / large / label / supporting / code），尺寸字重交给主题。
  • 标题用 Heading 的 level 1–6 输出正确的 h1–h6；视觉层级与文档层级不一致时补 accessibilityLevel。
  • 长文本 maxLines 截断（hover 出 tooltip 不丢字），数字列开 hasTabularNumbers 对齐位数。

不要

  • 跳级使用标题（h1 之后直接 h3）—— 读屏的文档大纲会断。
  • 再手动覆盖与语义 type 重复的字号字重 —— 和主题打架，换主题就崩。
  • 用 Link 做不导航的「动作」（那是 Button），也不用「点这里」这种没有信息量的链接文案。

关键 props

  • Text：children 必填 · type body / large / label / supporting / code / display-1~3 · maxLines · hasTabularNumbers · color
  • Heading：level 1–6 必填 · type display-1~3 · accessibilityLevel · maxLines
  • Blockquote：children 必填 · cite 出处（渲染成 <cite>）
  • Link：href · hasUnderline · isStandalone · isExternalLink · isDisabled
  • Kbd：keys 必填，+ 分隔，mod 自动跨平台
