进度与反馈 ProgressBar · Spinner · Skeleton · EmptyState · Banner

加载与状态反馈的全家桶：已知总量用 ProgressBar（确定 / 不确定两态），整体加载用 Spinner，形状已知的占位用 Skeleton，空内容用 EmptyState，需要用户看到并处理的常驻消息用 Banner。

meta-design · components/feedback/progress.html

什么时候用

  • 总量已知 → ProgressBar（value + max + hasValueLabel）；总量未知 → isIndeterminate。颜色走 variant：accent 常规、success 完成、warning / error 告警。
  • 内容尺寸已知 → Skeleton（用 index 错峰出波浪）；整体加载 → Spinner 并给 label；两者别叠在同一块区域。
  • 空列表 / 零结果 → EmptyState（title + 下一步按钮）；要用户处理的错误 / 提示 → Banner。

不要

  • 瞬时操作用进度条，或同一操作叠多条进度条。
  • Skeleton 无限加载下去 —— 太久就该给错误或空态。
  • 自动消失的短消息用 Banner → 那是 Toast；需要立即处理的错误用 EmptyState → 那是 Banner。
  • 空态写「暂无数据」这种泛化文案 —— 说清楚什么是空的、然后怎么办。

关键 props

  • ProgressBar：label 必填、value / max、isIndeterminate、hasValueLabel、variant、isDisabled、marks
  • Spinner：size sm / md / lg / xl、shade、label
  • Skeleton：width / height、radius、index
  • EmptyState：title 必填、description、actions、isCompact
  • Banner：status · title 必填、description、isDismissable、container card / section
