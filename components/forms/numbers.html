数值选择 Slider · NumberInput · SegmentedControl

「数字往哪儿走」的三种答法：Slider 探索连续区间（音量、价格带），NumberInput 精确输入带 min/max/step 与单位，SegmentedControl 在少数几个互斥档位 / 视图之间切换。全部受控，滑块和分段都能真的拖、真的点。

meta-design · components/forms/numbers.html

什么时候用

  • 连续区间用 Slider：始终给 label（可 isLabelHidden），用 formatValue 显示带单位的值（"75%"、"¥50"），刻度用 marks；需要精确数字时旁边配一个 NumberInput。
  • 精确数值用 NumberInput：设 min / max / step 引导合法值，用 units 标出 "%"、"GB"，粘贴 "1,234" 会在失焦时按 locale 解析成 1234。
  • 2–5 个互斥档位 / 视图用 SegmentedControl：选项全部可见，受控 value + onChange（存 useState），并给一个 label 作无障碍名。

不要

  • 拿 Slider 当精确输入，或 step 大到只有几个位置 —— 后者该用 SegmentedControl / 单选。
  • 用 SegmentedControl 做页面导航（那是 TabList）或简单开关（那是 ToggleButton）。
  • 用 NumberInput 装碰巧含数字的自由文本（用 TextInput），或同一字段同时 isOptional 与 isRequired。

关键 props

  • Slider：label + value 必填 · min/max/step · marks · formatValue · valueDisplay · 区间传 [min, max] · disabledMessage
  • NumberInput：label + value + onChange 必填 · min/max/step · units · hasNumberSteppers · hasClear（此时 onChange 会收到 null）· status
  • SegmentedControl：label + value + onChange + children 必填 · size · layout · disabledMessage
  • SegmentedControlItem：value + label 必填 · isDisabled
