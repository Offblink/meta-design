文本输入 TextInput

收集文字的三件套：TextInput 管单行短值（姓名、邮箱、搜索），TextArea 管多行内容（简介、留言，带字数计数器），Field 只负责给「自己写的控件」补上 label、帮助文本与校验状态——Astryx 自带外壳的输入不要再套一层 Field。所有输入均为受控，随主题与明暗切换即时变色。

meta-design · components/forms/text-input.html

什么时候用

  • 永远给可见的 label；只有上下文自明时（带图标的搜索框）才 isLabelHidden，读屏仍能读到。
  • 短值用 TextInput，多行内容用 TextArea：设 maxLength 就会带字数计数器，用户提交前就知道还剩多少。
  • 校验用 status 带 message 说明「错在哪」（"邮箱必须包含 @"），比只把边框染红有用得多；触屏场景补 type / inputMode / enterKeyHint / autoComplete，让键盘出对、AutoFill 能填。
  • 只有自己写的、没有外壳的控件才用 Field 包：它补 label、description 与 status，并用 inputID / descriptionID 接好 htmlFor 与 aria-describedby。

不要

  • 拿 placeholder 当 label —— 聚焦即消失，读屏也不可靠。
  • 把 TextInput / TextArea 再套进 Field —— 它们自带 Field 外壳，会嵌两层。
  • 所有字段都标 isRequired，或同一字段同时设 isOptional 与 isRequired。
  • 给禁用的输入包 Tooltip 解释原因 —— 用 disabledMessage，原因直接挂在字段上。

关键 props

  • TextInput：label 与 value 必填，配 onChange 受控
  • status = {type, message}，statusVariant attached / detached / tooltip
  • hasClear · type · inputMode · enterKeyHint · disabledMessage
  • TextArea：rows · maxLength（计数器）
  • Field：label + inputID + children 必填，description / statusVariant="detached"
