开关与选择 Switch · Checkbox · Radio

三类「二选一」控件的分工：Switch 拨了立即生效，CheckboxInput 是表单里的一项、可能带三态全选，RadioList 一组互斥选项全部摊开。全部受控（value + onChange 存在 React state 里），下面每个开关和选项都能真的点。

meta-design · components/forms/toggles.html

什么时候用

  • 立即生效的设置用 Switch：拨过去就保存，没有「提交」这一步；配简短的 label 说明在控制什么，异步生效用 changeAction（转圈直到 promise 完成）。
  • 要随表单提交才生效的勾选用 CheckboxInput；互斥选择用 RadioList：2–7 个选项、全部可见、给一个合理的默认选中值。
  • 「全选 + 部分选」用 CheckboxInput 的 value='indeterminate' 三态：子项有选有没选时，父项显示半选。

不要

  • 拿 Switch 承载需要点提交才生效的选项，或让它表示三档状态 —— 它严格 on/off。
  • 互斥选项用 Checkbox、长列表用 RadioList —— 分别该用 RadioList 和 Selector；横向 RadioList 超过 4 个会换行难看。
  • 给禁用的开关 / 复选 / 单选组包 Tooltip 解释原因 —— 禁用控件吞掉 hover，用 disabledMessage。

关键 props

  • Switch：label + value 必填 · changeAction · labelPosition / labelSpacing · size · status
  • CheckboxInput：label + value 必填（boolean | 'indeterminate'）· description · status · disabledMessage
  • RadioList：label + value + onChange + children 必填 · orientation · status
  • RadioListItem：label + value 必填 · description · isDisabled
