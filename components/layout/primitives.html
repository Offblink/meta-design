布局原语 Stack · HStack · VStack · Grid · Divider · Section

整套 Astryx 布局的范式参考页：单轴排列走 Stack（HStack / VStack 是预配置包装），二维网格走 Grid，分隔走 Divider，页面分区走 Section。间距一律用 0–10 的刻度数字（gap={4}），不手写 margin。

meta-design · components/layout/primitives.html

什么时候用

  • 间距与对齐只走刻度 props：gap / padding 传数字表达式（gap={4}），不手写 margin。
  • 单轴排列用 Stack（direction="horizontal" / "vertical"）或其包装 HStack / VStack；一个子项吃掉剩余空间用 StackItem size="fill"。
  • 多列布局用 Grid：columns={{minWidth: 240, max: 4}} 自动回流；分区用 Section，分区之间用 Divider 或 Section 的 dividers。

不要

  • 手写 CSS grid，或用 HStack + wrap 冒充网格 —— 那是 Grid 的活。
  • Stack 套 Stack —— 先试 wrap="wrap" 让内容换行。
  • 需要适配手机的行用 columns={4} —— 固定数字永不回流，手机上会挤成四条。
  • 该用 Section 的页面分区用 Card —— Card 是离散条目（一条通知、一张名片）。

关键 props

  • Stack / HStack / VStack：gap · padding 刻度数字，hAlign / vAlign，justify / align 别名，wrap
  • Stack direction horizontal / vertical（不是 "row"）；justify 用 'between' 不是 'space-between'
  • Grid：columns 数字或 {minWidth, max, repeat}、gap / rowGap / columnGap、align / justify
  • Divider：orientation、variant subtle / strong、label、isFullBleed
  • Section：variant section / transparent / muted、padding、dividers
