面包屑与分页 Breadcrumbs · Pagination

Breadcrumbs 回答「我在哪、怎么回去」，放在页面标题之上；Pagination 回答「还有多少、怎么翻」，放在内容之下。两者都是受控组件：本页用 useState 管面包屑跳转与页码，分页随页码联动渲染占位列表。

meta-design · components/nav/pagination.html

什么时候用

  • 详情页 / 设置面板顶部放 Breadcrumbs，位置在页面标题之上；最后一项标 isCurrent（组件自动 aria-current="page"）。
  • 表格下方放 Pagination：总数已知传 totalItems，只知道页数传 totalPages，游标式翻页用 hasMore。
  • 用户要控制每页条数 → count 变体 + pageSizeOptions；表格要跳页 → pages 变体；轮播 → dots 变体。

不要

  • 把面包屑当主导航 —— 它只是侧边栏 / 顶栏的补充。
  • 没有父级的顶层页面也挂面包屑，或层级超过 5 级。
  • 内容一页放得下还显示分页，或把分页放在内容上方。

关键 props

  • Breadcrumbs：children 必填，separator、variant default / supporting、label
  • BreadcrumbItem：children 必填，href、isCurrent、menu
  • Pagination：page · onChange 必填，totalItems / totalPages、variant pages / count / compact / dots / input、size sm / md、pageSize
