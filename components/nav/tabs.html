标签页 TabList

在几个相关视图之间切换而不离开当前页：TabList 是受控条（value + onChange），Tab 是单个标签。本页用 useState 驱动选中态，含 ARIA tabs 面板联动、三档尺寸、fill 布局与分隔线。

meta-design · components/nav/tabs.html

什么时候用

  • 同一上下文里切换几个相关视图（概览 / 动态 / 设置）→ TabList，受控 value + onChange。
  • 就地切面板时给条子 role="tablist"，每个 Tab 用 panelId 指向面板 id——这是读屏从标签跳到内容的唯一通道。
  • 与 hasDivider 同时放操作按钮时，把 Button 尺寸和 TabList 尺寸对齐（都 md 或都 sm），两者才会落在同一条基线上。

不要

  • 用标签页做顺序步骤 / 向导 —— 那是 Stepper 的活。
  • 超过 6–8 个可见标签还硬排 —— 把次要的收进 TabMenu。
  • 和 SegmentedControl / ToggleButton 搞混：TabList 是导航，后两者是输入控件。

关键 props

  • value · onChange 必填（TabList 受控对）
  • size sm / md / lg · layout hug / fill
  • hasDivider · role · overflow auto / scroll / visible
  • Tab：value · label 必填，panelId · href · endContent
