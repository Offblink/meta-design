对话框 Dialog

模态决策浮层：Dialog 承担一般确认与短表单，AlertDialog 只在破坏性操作前拦一道。开合由 useState 控制，点遮罩 / Escape 是否生效由 purpose 决定；打开时对话框进入浏览器顶层，覆盖整页。

meta-design · components/overlays/dialog.html

什么时候用

  • 一次性决策（发布、覆盖、确认）用 Dialog；带输入的短表单用 purpose="form"，点遮罩不会误丢数据。
  • 标题写清楚在问什么，正文说明后果，用户才敢按下按钮。
  • 对话框只聚焦单一任务；内容多到装不下，就该换成整页而不是加高。

不要

  • 简单消息别弹对话框 —— 能行内显示或用 Toast 的就别打断。
  • 不要嵌套对话框；把流程拆成同一个对话框里的步骤。
  • 破坏性操作别用普通 Dialog 确认 —— 用 AlertDialog（遮罩不可点、Escape 取消）。

关键 props

  • Dialog：isOpen / onOpenChange 必填；purpose info / form / required 决定关闭方式；width 默认 400
  • DialogHeader：title；传 onOpenChange 才有关闭按钮
  • AlertDialog：title / description / actionLabel / onAction 必填，onAction 不会自动关闭；isActionLoading 转圈；actionVariant 默认 destructive
