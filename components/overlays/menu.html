菜单 DropdownMenu · ContextMenu

两组动作列表：DropdownMenu 由按钮按开（鼠标按下即开，可拖进菜单选择），ContextMenu 由右键 / 长按在光标处打开。两者都用 items 数组声明分组、分隔线与破坏性项，选中即执行并自动关闭。

meta-design · components/overlays/menu.html

什么时候用

  • 一屏里的次要动作收进 DropdownMenu：分组（type:"section"）+ 分隔线（type:"divider"）让选项可扫读。
  • 右键 / 长按某块区域的就地操作用 ContextMenu；包住触发区域即可，菜单出现在光标处。
  • 破坏性项标 variant:"destructive"，禁用项标 isDisabled；动作型文案写「导出为 PNG」而不是「确定」。

不要

  • 别把导航塞进菜单 —— 跳页面用导航组件。
  • 单个菜单别超过 10–12 项不分组；重要操作别只挂在右键上（键盘用户按不出来）。
  • 非行内动作别混进 rows —— 按钮、开关放 header / footer 插槽。

关键 props

  • DropdownMenu：items 必填（action / divider / section 三种条目）；button 是触发按钮的 Button props（不含 onClick）；placement 默认 below；menuWidth、hasChevron 默认 true
  • 条目字段：label / onClick / variant / isDisabled / endContent（尾部快捷键提示）
  • ContextMenu：children 必填是触发区域；items 与 menuContent 二选一；label、menuWidth 默认 160px、presentation 默认 popover
