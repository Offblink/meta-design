弹出与提示 Popover · Tooltip · HoverCard · InfoTip

锚定在触发元素上的非模态浮层：点击开合的 Popover、悬停一现的 Tooltip、悬停看资料的 HoverCard、常驻行内的 InfoTip。四种都由组件自己定位与播动画，这里只负责内容与触发。

meta-design · components/overlays/popover.html

什么时候用

  • 一次点击能完成的次要动作（导出、分享）用 Popover，内容聚焦单一任务，点外部或 Esc 关闭。
  • 一句话补充、图标按钮的说明用 Tooltip；正文控制在 140 字符内。
  • 需要悬停预览的富内容（成员卡、链接摘要）用 HoverCard；标签旁的字段解释用 InfoTip（自带可聚焦的 i 按钮，点一下钉住）。

不要

  • Tooltip 里放链接或按钮 —— 悬停即消失，用户够不到；换成 HoverCard 或 Popover。
  • 关键信息别只放在悬停浮层里 —— 键盘与触屏用户可能永远看不到。
  • 不要把 Popover 嵌套进 Popover —— 焦点与关闭顺序会乱。

关键 props

  • Popover：content 必填、触发里要有 button；placement above / below / start / end；alignment；hasLightDismiss、label
  • Tooltip：content、delay 默认 200ms、focusTrigger、touchTrigger
  • HoverCard：content 必填、delay 300 / hideDelay 200、label（给了就是具名 dialog）
  • InfoTip：content 必填、label 默认「More information」、size xsm / sm / md / lg
