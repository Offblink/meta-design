抽屉与底部面板 Drawer · BottomSheet

贴边浮层：Drawer 从行内轴（左 / 右）滑入，做「点一行看详情」的检查器，列表始终可见；BottomSheet 从块轴（底部）升起，做触屏上的筛选、分享与步骤流。两者都是受控组件，开合状态由 useState 持有，动画与定位由组件自己负责。

meta-design · components/overlays/sheets.html

什么时候用

  • 「点一行看详情」用 Drawer：浮在内容之上，背后的列表还在，Escape / 遮罩 / 关闭按钮都能退出。
  • 触屏上的筛选、分享、快捷动作用 BottomSheet：内容装不下就分步，每步一个 sheet，一个状态值命名当前步骤。
  • 表单放抽屉里用 purpose="form"：Escape 仍可退出，但点遮罩不会丢掉输入。

不要

  • 短确认、小表单别开抽屉 —— 用 Dialog / AlertDialog。
  • 内容该把页面顶开时别用浮层 —— 那是 docked panel（布局列）的活。
  • BottomSheet 别堆超过两三层；步骤间用「关一个、开一个」替换，而不是层层叠。

关键 props

  • Drawer：isOpen / onOpenChange / label 必填；side start / end（默认 end）；width 默认 400；hasScrim 默认 true
  • DrawerHeader：title 必填；传 onOpenChange 才有关闭按钮（Drawer 自己不画关闭键）
  • BottomSheet：label / children 必填；height hug / capped / tall（默认 capped）；snapPoints 给出可拖停的高度
