主题与 Token

Astryx 的主题 = 一组 CSS 自定义属性覆盖。每套主题编译成一个 theme.css，用 @scope([data-astryx-theme]) 圈住自己的作用域 —— 所以七个文件可以同时加载，切主题只是换一个 html 属性，零网络请求。下方所有色块都实时跟随上方主题与明暗开关。

主题怎么工作

  • 198 个 CSS 自定义属性就是全部主题状态 —— 没有 JS 运行时换肤，没有 inline style。
  • 每个主题一个 theme.css，用 @scope([data-astryx-theme="…"]) 圈作用域，七个文件同时加载互不打架。
  • 切主题 = 改 <html data-astryx-theme>，零请求、即时生效（见上方 pill）。
  • 明暗双模靠 light-dark()：token 值成对写好，data-theme="dark" 翻转 color-scheme 即可。

怎么定制

  • 覆盖变量即可，不用 fork 组件：
  • [data-astryx-theme] { --color-text-accent: #e85d04 }
  • 想生成整套主题：defineTheme() + astryx theme build（本仓库 7 套就是这么编译出来的）。

token 分层

  • 角色层：--color-text-primary 这类语义名 —— 组件只认角色
  • 主题层：每套主题把角色映射到具体色值
  • 所以换主题不用改任何组件 CSS

本页特点

  • 纯 HTML/CSS，没有挂 React —— token 层本来就不需要它（这正是选 Astryx 的理由）。
