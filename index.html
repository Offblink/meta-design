meta-design

React 版静态组件画廊 —— 把 Meta 开源设计系统 Astryx（120 个组件 · 7 套主题 · MIT）搬进双击即开的 HTML。 React 19 + Astryx 运行时已预打包进 vendor/astryx.js，无需 npm、无需构建、file:// 直接可用； 七套主题 CSS 全量预载，切主题 = 换一个 html 属性。
